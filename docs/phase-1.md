# Phase 1: AI Therapist Chat MVP

## Overview
Phase 1 implements a secure, working AI Wellness Companion MVP with anonymous and authenticated sessions, persistent chat history in Cloud Firestore, and empathetic AI responses generated by Google Gemini.

## Features Implemented
1. **Authentication:**
   - Anonymous sign-in ("Continue without account").
   - Email and password sign-up and sign-in.
   - Synchronized user profile document at `users/{uid}`.
   - Protected route navigation (unauthenticated users redirected to `/login`).

2. **Session Creation & History:**
   - Automatically initializes a session upon starting a conversation or via "+ New chat".
   - Generates session titles from the first user message (truncated cleanly to <= 50 characters).
   - Real-time session listing in the left sidebar ordered by `updatedAt` descending.
   - Formats relative timestamps ("Today", "Yesterday", or "12 Mar").
   - Restores message history on selecting any previous session.

3. **Real-Time Responsive Chat Interface:**
   - Calming, accessible aesthetic based on `docs/DESIGN.md` (flat style, Daylight cards, Midnight Mouth pill buttons, no heavy shadows).
   - Optimistic message rendering: user messages appear immediately before server response.
   - Animated typing indicator while awaiting Gemini completion.
   - Graceful error state with a "Retry" button.
   - Persistent emergency disclaimer banner:
     *"This AI companion is not a therapist and does not provide medical advice. In an emergency, contact local emergency services."*
   - Keyboard support: `Enter` sends message, `Shift+Enter` inserts a newline.

4. **Gemini Chat Endpoint:**
   - Endpoint: `POST /api/chat`
   - Validates Firebase ID tokens via Bearer token in the `Authorization` header using Firebase Admin SDK.
   - Verifies session ownership to prevent cross-user data tampering.
   - Persists user messages before AI generation.
   - Retrieves the last 20 messages for conversational context.
   - Prompts Google Gemini with a non-judgmental, empathetic therapist system instruction.
   - Configurable model via `GEMINI_MODEL` (default: `gemini-2.5-flash`).
   - Persists assistant responses and updates session message count and timestamps.
   - Returns HTTP 502 with friendly error messaging when Gemini fails without storing empty responses.

## Firestore Data Model

### `users/{uid}`
```typescript
{
  uid: string;
  email: string | null;
  isAnonymous: boolean;
  createdAt: Timestamp;
}
```

### `sessions/{sessionId}`
```typescript
{
  uid: string;
  title: string;
  status: "active" | "ended";
  createdAt: Timestamp;
  updatedAt: Timestamp;
  messageCount: number;
}
```

### `sessions/{sessionId}/messages/{messageId}`
```typescript
{
  role: "user" | "assistant";
  text: string;
  createdAt: Timestamp;
}
```

## API Contract

### `POST /api/chat`
- **Headers:** `Authorization: Bearer <FIREBASE_ID_TOKEN>`
- **Request Body:**
```json
{
  "sessionId": "string",
  "message": "string"
}
```
- **Responses:**
  - `200 OK`:
    ```json
    {
      "role": "assistant",
      "text": "Empathetic response text...",
      "createdAt": "2025-03-12T10:00:00.000Z"
    }
    ```
  - `400 Bad Request`: Validation failure (missing sessionId or message).
  - `401 Unauthorized`: Missing, expired, or invalid token.
  - `403 Forbidden`: User does not own the requested session.
  - `404 Not Found`: Session does not exist.
  - `502 Bad Gateway`: AI provider failure (user message is saved, allowing retry).

### `POST /api/chat/sessions`
- **Headers:** `Authorization: Bearer <FIREBASE_ID_TOKEN>`
- **Request Body:** `{ "title"?: "string" }`
- **Response:** `201 Created` with created session doc.

### `GET /api/chat/sessions`
- **Headers:** `Authorization: Bearer <FIREBASE_ID_TOKEN>`
- **Response:** `200 OK` with `{ "sessions": Session[] }`.

### `GET /api/chat/sessions/:sessionId/messages`
- **Headers:** `Authorization: Bearer <FIREBASE_ID_TOKEN>`
- **Response:** `200 OK` with `{ "messages": Message[] }`.

## Environment Variables

### Frontend (`frontend/.env`)
- `VITE_FIREBASE_API_KEY`: Firebase web API key.
- `VITE_FIREBASE_AUTH_DOMAIN`: Firebase auth domain.
- `VITE_FIREBASE_PROJECT_ID`: Firebase project ID.
- `VITE_FIREBASE_STORAGE_BUCKET`: Firebase storage bucket.
- `VITE_FIREBASE_MESSAGING_SENDER_ID`: Firebase messaging sender ID.
- `VITE_FIREBASE_APP_ID`: Firebase web app ID.
- `VITE_API_BASE_URL`: Base URL for backend service (default: `http://localhost:8080`).

### Backend (`backend/.env`)
- `PORT`: Server port (default: `8080`).
- `GEMINI_API_KEY`: Google Gemini API key.
- `GEMINI_MODEL`: Gemini model identifier (default: `gemini-2.5-flash`).
- `FIREBASE_PROJECT_ID`: Firebase admin project ID.
- `FIREBASE_CLIENT_EMAIL`: Service account client email.
- `FIREBASE_PRIVATE_KEY`: Service account private key (escaped newlines supported).

## Known Limitations & Phase 2 Deferred Scope
The following features are intentionally deferred to Phase 2 and Phase 3:
- Crisis and active self-harm detection triggers / emergency service redirects.
- Automated session summaries and theme tracking.
- Structured coping-step generation and action plan workflows.
- Usage metrics and analytics dashboards.
- Cloud deployment automation and CI/CD pipelines.
